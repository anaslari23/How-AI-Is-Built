              Deep Dive 4B
              3D Parallelism Topology (TP × PP × DP)
            

            

              

                
1. Tensor Parallelism (TP = 8 within NVLink Node)

                
Splits individual matrix multiplications (WQ, WK, WV, WMLP) column-wise and row-wise across 8 GPUs connected by 900 GB/s NVLink.

              

              

                
2. Pipeline Parallelism (PP = 4 across Nodes)

                
Assigns sequential groups of Transformer layers (e.g., Layers 1–20 on Node 1, 21–40 on Node 2) using 1F1B micro-batch scheduling.

              

              

                
3. Data Parallelism (DP/FSDP = 128 Replicas)

                
Each replica processes different token batches and synchronizes gradients via All-Reduce / Reduce-Scatter over InfiniBand.

              Deep Dive 8B
              Two-Phase Inference Bottleneck: Prefill vs. Autoregressive Decode
            

            

              

                
Phase 1: Prompt Prefill (Compute-Bound)

                
Processes all N input prompt tokens in parallel via matrix-matrix multiplication (GEMM). Saturates GPU Tensor Cores; determines Time-To-First-Token (TTFT).

              

              

                
Phase 2: Token Decode (Memory-Bound)

                
Generates 1 token at a time via matrix-vector multiply (GEMV). Must stream all model weights + KV-Cache from HBM memory for every single token; determines Inter-Token Latency (ITL).

        Foundation 1 of 3
        
Basics: How a Machine Learns from Examples

        
Three ideas sit under every AI model: learning without memorizing, numbers as arrows, and teaching by example. Guess first, then play.

      

      

        
      

      

        

          
1. Learn, Don't Memorize (overfitting and regularization)

          

          
The model fits a curve through the blue training points. The orange circles are new data it has never seen. A good model does well on both.

          

            
            
          

          
Training examples:
            

          
          

          
          
Where is this used in AI?
Billions of weights can memorize their training data. Models are kept honest by testing on unseen data, using more data, and penalties such as weight decay and dropout. Training error keeps falling, but what matters is the error on new data.

        


        

          
2. Numbers as Arrows (vectors, dot product, softmax)

          

          
A model stores each word as a list of numbers, an arrow. Arrows pointing the same way mean similar things.

          
Try:
            

          

            
            
            
          

          
          

          

            
Scores to probabilities (softmax). The model scores each next word. Softmax turns scores into probabilities that add up to 100%.

            

              
              
              
            

            

          

          
Where is this used in AI?
Embeddings are these arrows with hundreds or thousands of numbers. Attention compares them with dot products, and search finds similar text by cosine similarity. Softmax turns the final scores into next-word probabilities, which the Randomness page then samples from.

        


        

          
3. Teach with a Prompt (in-context learning)

          

          
You can steer a trained model by putting worked examples in the prompt. Nothing is retrained. Replies below are scripted to illustrate the idea, not a live model.

          
Task:
            

          
          
Your prompt

          

          
Model reply

          

          

          
Where is this used in AI?
This is "few-shot prompting". The model's weights stay frozen; it simply reads the examples inside its context window and continues the pattern. Longer prompts use more of the context window, so every example has a cost.

        

      

      

        
        
      

    


    

      

        

          

            Foundation 2 of 3
            
Randomness: From Random Walks to Diffusion and LLM Sampling

            
Every AI model runs on controlled randomness. Guess first, play with each demo, then check your guess. Ideas from The Nature of Code, Ch. 0: Randomness.

          

          

            
            
            
          

        

        
Computers use a pseudorandom generator: same seed, same "random" numbers. Change the seed to re-roll every demo.

      


      

        
        
        
        
      

      


        
        

          
1. Random Walks (Nature of Code §Random Walks, Walker class)

          

          
Pick a step rule and watch the walker.

          

            
            
            
            
          

          
          

          
Where is this used in AI?
SGD is a noisy walk through weight space. Diffusion and MCMC are random walks too.

        


        
        

          
2. Gaussian Noise to Diffusion Models (Normal distribution)

          

          
Drag the slider and watch a shape dissolve into noise, the way image generators are trained.

          

            
            
            
          

          
          

          
Where is this used in AI?
The network learns to predict the added noise. Generating an image runs the process backwards from pure noise.

        


        
        

          
3. Distributions and Weight Initialization (Uniform vs Normal, mean and standard deviation)

          

          
Try:

          
Send a random signal through 20 layers. The wrong spread makes it vanish or explode.

          

            
            
            
          

          
          

          
Where is this used in AI?
Xavier and He set the spread from the layer width so signals stay steady in deep networks.

        


        
        

          
4. Custom Distributions: Accept-Reject (Monte Carlo method)

          

          
Keep a random r1 only if a second random r2 is below r1k.

          

            
            
            
          

          
          

          
Where is this used in AI?
Speculative decoding accepts a draft token with probability min(1, p/q). Best-of-N is a close cousin.

        


        
        

          
5. How an LLM Picks the Next Word (Nonuniform distributions and range partitioning)

          

          
Try:

          
Prompt: "The cat sat on the ___". Reshape the scores, then a random number picks a slice of the strip.

          

            
            
            
          

          

          

            
Probability strip: the black marker is the random number drawn for the last sample.

            

          

          

            
            
            
          

          
Where is this used in AI?
Low temperature is predictable, high is creative. Top-k and top-p trim the unlikely tail. Every reply is thousands of draws.

        


        
        

          
6. Perlin-Style Noise: Smooth vs Jagged (Perlin noise, octaves)

          

          
Jagged white noise vs smooth noise. Bottom: layered 2D noise (clouds, terrain).

          

            
            
          

          
          
          

          
Where is this used in AI?
Real data is locally smooth. Moving smoothly through a latent space morphs images; random jumps give garbage.

        


        
        

          
7. Multiplying Probabilities: Why Long Answers Go Wrong (Probability basics, Monte Carlo)

          

          
Three heads in a row is (1/2)3 = 12.5%. An answer is a chain of token choices.

          

            
            
          

          

          

          
Where is this used in AI?
P(answer) is the product of token probabilities, so long outputs drift. pass@k is estimated with random trials.

        Foundation 3 of 3
        
Neural Networks: Learning by Adjusting Weights

        
A neural network is many tiny neurons that weigh their inputs. Learning means nudging the weights to shrink the error. Ideas from The Nature of Code, Ch. 10: Neural Networks. Random starting weights come from Foundation 1.

      

      

        
        
      

      

        

          
1. One Neuron (inputs, weights, bias, activation)

          

          
Click the plot to move the input. Drag the sliders to change the neuron.

          

            
            
            
          

          
Activation:
            

          
          

          
Where is this used in AI?
Every layer of every model is many of these neurons in parallel. The weights and biases are the "parameters": 7 billion of them in a 7B model.

        


        

          
2. Teach a Neuron (perceptron training rule)

          

          
Start with random weights. Each mistake nudges them: new weight = weight + error x input x learning rate.

          

            
            
            
            
          

          
          
          

          
Where is this used in AI?
This is supervised learning in miniature: guess, measure the error, adjust. Modern models use backpropagation and the AdamW optimizer, but the loop is the same.

        


        

          
3. Add a Hidden Layer (multilayer network, backpropagation)

          

          
Pattern:
            

          

            
            
          

          

            
            
          

          

            
            
          

          

          
Where is this used in AI?
Hidden layers let a network bend its decision boundary. Training repeats forward pass, loss, backward pass and update, which is Stage 4 pre-training at tiny scale. Transformers stack many such layers.
