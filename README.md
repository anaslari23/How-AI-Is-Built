# How AI Is Built

Free, interactive study material on how AI models are built. Start with randomness and neural networks, then follow a language model from raw data to deployment. Change a setting and watch what happens.

## What you will learn

1. **Basics:** learning without memorizing (overfitting), numbers as arrows (vectors and softmax), teaching a model with a prompt
2. **Randomness:** random walks, diffusion, weight initialization, how LLMs sample the next word
3. **Neural networks:** a single neuron, the perceptron, a small network that learns XOR
4. **The model lifecycle:** data, tokenization, architecture, pre-training, fine-tuning, alignment, evaluation, deployment
5. **Beyond the basics:** mixture of experts, distillation, retrieval, FlashAttention, diffusion
6. **Test yourself:** a glossary and a short quiz
