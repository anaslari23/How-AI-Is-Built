# How AI Is Built

An interactive, single-page guide to how AI models are built, from randomness and neural networks through data, tokenization, architecture, pre-training, fine-tuning, alignment, evaluation and deployment.

- Learning path: Randomness, Neural Nets, then 8 lifecycle steps, ending with a glossary and quiz
- Simulators and 3D scenes you can change and watch react
- Dark OLED and light themes, works on mobile

## Run it

It is one HTML file with no build step. Open `interactive_ai_model_building_roadmap_simulator.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8765
```

Then visit http://127.0.0.1:8765/interactive_ai_model_building_roadmap_simulator.html
