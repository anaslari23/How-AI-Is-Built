# How AI Is Built

Free, interactive study material on how AI models are built. Start with randomness and neural networks, then follow a language model from raw data to deployment. Change a setting and watch what happens.

## What you will learn

1. **Randomness:** random walks, diffusion, weight initialization, how LLMs sample the next word
2. **Neural networks:** a single neuron, the perceptron, a small network that learns XOR
3. **The model lifecycle:** data, tokenization, architecture, pre-training, fine-tuning, alignment, evaluation, deployment
4. **Beyond the basics:** mixture of experts, distillation, retrieval, FlashAttention, diffusion
5. **Test yourself:** a glossary and a short quiz
